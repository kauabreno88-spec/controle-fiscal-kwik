# Controle Fiscal KWIK — app

App do controle de despesas fiscais da KWIK Contabilidade Inteligente, publicado pelo GitHub Pages para instalar no iPhone (Safari → Compartilhar → Adicionar à Tela de Início).

Este repositório tem **só o código**. Os dados ficam num repositório privado e são acessados com um token guardado em cada aparelho.

## KWIK Folha (`/folha/`)

A pasta `folha/` tem o app da folha de pagamento (mesmo esquema: só o código). Os dados ficam no repositório privado **KWIK-FOLHA-**, que é onde o app é mantido; esta pasta é só uma cópia para o GitHub Pages. Nunca copie a pasta `dados/` para cá.

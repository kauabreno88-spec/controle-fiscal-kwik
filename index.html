    Como usar

    O mesmo controle da planilha, no computador e no celular.

    1

    Empresas

    Cadastre cada cliente (razão social, CNPJ, regime tributário).

    2

    Lançamentos

    Registre cada guia: empresa, tributo, competência, vencimento e valores. Regime, esfera, total e status são automáticos.

    3

    Resumo

    Escolha o ano e, se quiser, uma empresa. Os totais por mês, tributo e status se atualizam sozinhos.

    4

    Tributos

    Lista usada nos menus. Pode incluir novos tributos ou taxas a qualquer momento.

    Legenda

    Campo verde-claroCampo para preencher.
    Campo tracejadoCálculo automático (regime, esfera, total e status) — não precisa editar.
    PagoTem data de pagamento.
    A vencerSem pagamento e vencimento hoje ou depois.
    VencidoSem pagamento e vencimento já passou (calculado pela data de hoje).
    Sem venc.Sem pagamento e sem data de vencimento.
    3Dias p/ vencer destacado quando faltam 5 dias ou menos (negativo = dias de atraso).

    Onde os dados ficam salvos

    O banco é o arquivo dados/kwik-despesas.json do seu repositório privado no GitHub. Cada aparelho guarda uma cópia e sincroniza sozinho: ao abrir o app, ao salvar e ao voltar para ele. Cada envio vira um commit, então o GitHub guarda o histórico de tudo.

    Conectar um aparelho

    Toque em Banco de dados → Conectar ao GitHub, gere um token com acesso só a esse repositório (as instruções estão na tela) e cole. Faça isso uma vez em cada aparelho.

    Sem internet

    Pode lançar normalmente. As alterações ficam guardadas no aparelho e sobem quando a conexão voltar. Se o celular e o computador mexerem ao mesmo tempo, as alterações se juntam: em cada lançamento vale a mais recente.

    Instalar no iPhone

    Abra o link do app no Safari, toque em Compartilhar → Adicionar à Tela de Início. Depois abra pelo ícone e conecte ao GitHub ali dentro.

    Excel

    Exportar para Excel gera um .xlsx com as abas Resumo, Lançamentos, Empresas e Tributos. Importar planilha lê uma planilha no mesmo formato e substitui os dados.

    Origem

    Dados de agosto e setembro/2026 lançados a partir das guias do Drive da KWIK.

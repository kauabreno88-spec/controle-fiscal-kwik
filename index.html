          Como usar

          Início

          Escolha o ano e a empresa nos botões do topo. O número grande é o que falta pagar; toque em qualquer parte dos gráficos para ver as guias.

          Guias

          Busque, filtre pelo status e toque em Pagar para dar baixa com a data de hoje. Toque na guia para editar, duplicar para o mês seguinte ou excluir.

          Botão ＋

          Lança uma guia nova. Regime, esfera, total e status são calculados sozinhos.

          Status

          Pago: tem data de pagamento. Vencido: o vencimento já passou. A vencer: vence hoje ou depois. Sem venc.: sem data de vencimento.

          Onde ficam os dados

          No arquivo dados/kwik-despesas.json do seu repositório privado no GitHub. O app sincroniza ao abrir, ao salvar e ao voltar para ele; sem internet, guarda as alterações e envia depois.

          Instalar no iPhone

          No Safari: Compartilhar → Adicionar à Tela de Início. Conecte ao GitHub dentro do app instalado.

          Tributos

          Toque para editar. As setas mudam a ordem dos menus.
